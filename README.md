# World War — بازی استراتژی جهانی

## اجرا روی Railway
1. این پوشه رو به یک ریپوی گیت‌هاب پوش کن.
2. توی Railway یک پروژه‌ی جدید از همون ریپو بساز (New Project → Deploy from GitHub Repo).
3. Railway خودش Node.js رو تشخیص میده و با `npm start` اجرا می‌کنه (فایل railway.json همراهشه).
4. یک متغیر محیطی لازم نیست؛ فقط مطمئن شو پوشه‌ی db روی یک Volume دائمی مونت شده
   (Settings → Volumes → مسیر /app/db) تا دیتابیس بعد از ریدیپلوی پاک نشه.
5. بعد از دیپلوی، آدرس عمومی Railway رو باز کن — صفحه‌ی ورود بازی میاد.

## ساختار
- server.js — بک‌اند Express + Socket.io (API احراز هویت، کشورها، فروشگاه، هک/حمله)
- db.js — اسکیمای SQLite (better-sqlite3) + دیتای اولیه‌ی فروشگاه
- countries.js — لیست کشورها و مختصاتشون روی نقشه
- public/ — فرانت‌اند (نقشه‌ی SVG انیمیشنی، فروشگاه، کوله‌پشتی، لیدربورد)

## مکانیزم فعلی
- هر بازیکن یک کشور آزاد انتخاب می‌کنه (هر کشور فقط برای یک نفر).
- ماینر: ۷۰۰ دلار بر ساعت، به‌صورت خودکار جمع می‌شه و با دکمه‌ی «برداشت ماینر» واقعی می‌شه.
- فروشگاه: سپر دفاعی، ابزار هک، ابزار قطع اینترنت، سلاح حمله، ارتقای ماینر.
- هک: درصدی از موجودی هدف رو می‌دزده؛ شانس موفقیت به سطح سپر هدف بستگی داره.
- قطع اینترنت: ماینر هدف رو برای چند دقیقه متوقف می‌کنه؛ سپر شانس دفاع رو بالا می‌بره.
- حمله نظامی: مقایسه‌ی قدرت حمله در برابر سپر، در صورت موفقیت غنیمت می‌گیره.
- همه‌ی رویدادها لحظه‌ای با Socket.io برای همه‌ی بازیکن‌ها پخش و روی نقشه با افکت «بیم» نمایش داده می‌شه.

## قدم بعدی (اگه خواستی ادامه بدیم)
- اتحاد/ائتلاف بین بازیکن‌ها
- سطح‌بندی کشورها (نرخ پایه‌ی ماینر متفاوت برای هر کشور)
- چت بین بازیکن‌ها
- انیمیشن‌های پیشرفته‌تر (ذرات، نقشه‌ی واقعی‌تر)
